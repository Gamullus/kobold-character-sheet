# Kobold Character Sheet

A focused **D&D 5e 2014** character builder and live-play tracker.

## Product direction

- 2014 rules only
- Designed for new players
- ADHD-friendly, low-clutter interface
- Character creation should be guided step by step
- Main sheet optimized for play, not data entry
- Resources are directly clickable in real time
- Skills live in a pull-out drawer instead of cluttering the main screen
- Homebrew support for custom items, feats, bonuses, ASIs, and features
- Visual direction: **Lucifer RPG UI** pixel-RPG framing and accents, while keeping text and controls highly readable

## Current prototype

The first prototype includes:

- Ability scores at the top
- AC, Initiative, Speed, and Proficiency summary
- Interactive HP damage/healing
- Saving throws directly below HP
- Quick "What can I do?" turn actions
- Clickable Wild Shape and spell-slot resources
- Short Rest / Long Rest resource restoration
- Pull-out Skills panel
- Responsive mobile layout

Open `index.html` directly in a browser to run the prototype.
